# Skyrim Bookmarks

# What does it do?

Saves the page you're on when closing the book menu in Skyrim. Opening the same book again will automatically snap to the saved page for said book.
Official Nexus Mods Page: [Skyrim Bookmarks](https://www.nexusmods.com/skyrimspecialedition/mods/195984)

# CommonLibSSE NG

Because this uses [CommonLibSSE NG](https://github.com/alandtse/CommonLibSSE-NG), it supports Skyrim SE, AE, GOG, and VR.

[CommonLibSSE NG](https://github.com/alandtse/CommonLibSSE-NG) is a fork of the popular [powerof3 fork](https://github.com/powerof3/CommonLibSSE) of the _original_ `CommonLibSSE` library created by [Ryan McKenzie](https://github.com/Ryan-rsm-McKenzie) in [2018](https://github.com/Ryan-rsm-McKenzie/CommonLibSSE/commit/224773c424bdb8e36c761810cdff0fcfefda5f4a). 

# Template
This uses the [commonlibSSE NG Template](https://github.com/libxse/commonlibsse-ng-template) provided by qudix, 
which uses the [CommonLibSSE NG](https://github.com/alandtse/CommonLibSSE-NG) fork by alandtse.
